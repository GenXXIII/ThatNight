# THAT NIGHT

Open **ChapterOne-Environment/Open Unity Project.cmd** for the current Chapter 1 project.

Edit and save `Assets/ChapterOne/Scenes/ChapterOneEnvironment.unity`, then choose
**THAT NIGHT > Build current Chapter 1 preview**. Builds preserve your edited map.

Use **Play Chapter 1 - The Wedding.cmd** for the current story, or
**ChapterOne-Environment/Preview Environment.cmd** for environment inspection.
Both use the current `Builds/ChapterOne/THAT NIGHT.exe` output.

See [editing instructions](ChapterOne-Environment/README.md) and
[project structure](ChapterOne-Environment/Docs/Architecture.md).
